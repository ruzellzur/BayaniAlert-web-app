BayaniAlert — 20 screens, one map

The standalone prototype is a single-page vanilla build: every screen is a <section class="screen"> and one function, go(id), decides which one is visible. Pick a screen on the left to load it in the frame.

How navigation is wired. go(id) shows one screen and then marks the matching shell tab active through tabMap — sub-screens light up their parent: resourceDetail, listResource, myRequests and thread all belong to the Board tab; evacDetail belongs to Map; weatherHistory to Home; directory to Profile.
Login routing.
  • resident → home
  • official → announcements + body.role-official
  • admin → adminApprovals (swaps in the admin sidebar and tabbar)
Same state as the React app. Both builds persist to localStorage['bayanialert_state'], so a stale session in one shows up as a logged-in user in the other.
